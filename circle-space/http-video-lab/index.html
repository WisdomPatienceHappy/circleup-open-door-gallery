How to compare results

Keep count, footage, quality, playback policy, device and connection fixed. Change only the view. Run three trials per view in alternating order. Tap Next focus, zoom and drag during each trial. Repeat with a second network if useful. Save the JSON before closing the tab.

All requested videos remains the load target in every view. Nearest 6 changes the workload and unloads other URLs. Actual active and completed counts are in the results. The first trial and repeated trials have different cache histories.

The frame interval samples the UI animation loop. Input → frame measures event handling through two animation callbacks, a proxy for response before display scanout.
